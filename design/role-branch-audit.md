# 역할별 모바일 UX 감사

검증일: 2026-08-04

## 흐름별 결과

1. 로그인 후 역할 분기 — 양호
   - `platform_admin`, `minister`, `executive`는 관리자 홈으로 이동한다.
   - `member`는 성도 홈으로 이동한다.
   - 일반 회원이 `/manage/*`를 직접 열면 내 정보 화면으로 돌아간다.
2. 관리자 홈 — 양호
   - 관리 범위, 승인 대기, 회원 또는 교회 현황, 빠른 작업, 최근 활동을 실제 데이터로 표시한다.
   - 플랫폼 관리자와 교회 관리자의 내비게이션 및 지표 범위를 구분한다.
3. 성도 홈 — 양호
   - 승인·회원관리 카드를 제거하고 공지, 글쓰기, 기도 나눔, 사진·영상, 최근 글, 예배 일정을 우선한다.
   - 집사·권사·장로 같은 직분을 인사와 프로필에 표시하되 관리 권한에는 사용하지 않는다.
4. 관리자 세부 화면 — 양호
   - 가입 승인과 회원 관리에서도 관리자 셸과 하단 내비게이션을 유지한다.
   - 가입 신청과 회원 목록에서 권한 역할과 교회 직분을 함께 확인할 수 있다.
5. 화면 전환 — 양호
   - 관리자 화면과 성도 화면 사이를 명시적으로 전환할 수 있다.
   - 경로가 바뀔 때 스크롤을 맨 위로 복원한다.
6. 모바일 접근성 — 양호
   - 주요 버튼, 필터, 회원 상태 작업, 검색 지우기 버튼을 최소 44px 터치 영역으로 맞췄다.
   - 360~389px 헤더 축약, `100dvh`, 상·하단 safe-area 여백, 5개 하단 탭을 적용했다.
