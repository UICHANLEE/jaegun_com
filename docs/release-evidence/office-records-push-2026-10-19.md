# 회의록·회계 GitHub 반영 범위

2026-10-19. 운영 main 기준 커밋 `62d1fbb`에서 `codex/office-records-and-operations` 검증 브랜치로 반영한다.

## 기능

- 웹 더보기의 독립 회의록·회계 진입, SwiftUI 권한 범위의 임원 기록 진입.
- 조직·명시적 행사·연도별 회의록 수동 작성, 초안/확정, 수정·변경 이력·삭제 이력.
- 범위별 수입/지출, 취소 역분개와 원본 보존, 비공개 영수증, 결산·XLSX, 기간 마감.
- 서버 권한 확인, 최근 Google 인증, revision/operation UUID 기반 재시도 계약을 보존한다. 일반 성도·사역자에게 메뉴만으로 권한을 부여하지 않는다.
- 권한 조회 로딩과 실제 권한 없음, 기록 조회·빈 상태를 구분한다. 저장 중 편집 및 중복 요청을 차단한다.
- 앞선 관제·감사·이의신청과 AI 없는 도구 랜딩 변경도 포함한다. 화면 의존성이 있는 앞선 조직·게시판·채팅·일정 소스와 정적 성경 자산을 함께 추적하여 새 체크아웃의 누락을 방지한다.

## 확인

- 최종 독립 체크아웃 전체 웹 테스트: 65개 파일, 502개 통과 (4 workers, 28.93초).
- 웹 TypeScript, production build, production 데모 노출 차단 검사 통과.
- 스테이징 파일만 추출한 독립 체크아웃에서도 웹 빌드·타입 검사, 테마·런타임·서버 보안 검사와 SwiftUI Debug 컴파일을 확인했다. 의존성은 기존 node_modules/Pods를 재사용했으므로 새 의존성 다운로드·설치 검증은 아니다.
- 독립 체크아웃 첫 기본 병렬 실행에서는 기존 첨부 교체 테스트 하나가 5초 제한에 걸렸다. 단독 재실행은 통과했고, 제한 시간을 늘리지 않은 2-worker 전체 재검증은 501개 모두 통과했다. 최종 권한 조회 재시도 수정은 회의록·회계 8개 테스트로 추가 확인했다.
- 서버 Edge 보안 검사 42개 통과. 실제 영수증 파일 업로드나 실제 장부 작성·기간 마감을 테스트 목적으로 실행하지 않았다.
- 회계·회의록 운영 DB pgTAP: 68개 통과, 합성 데이터 전부 롤백. 실제 회원·제재·장부는 테스트 목적으로 변경하지 않았다.
- 테마 토큰 5개 검사와 레거시 보호 런타임 28개 파일 무결성 검사 통과.
- 비밀정보 스캔 통과. 기기별 public config, 개인 자료, 인증 정보, Pods 및 빌드 산출물은 제외한다.

## 구분

이번 요청의 push는 검증 브랜치 원격 저장이며, main 병합·Vercel 운영 배포·새 iPhone 설치 또는 App Store 출시가 아니다. 화상회의·라이브에 누락된 운영 RPC 4개는 별도 출시 차단 항목으로 남는다. 이를 통과시키기 위해 관련 DB를 일괄 적용하지 않는다.

AI 서버·사용량·미디어 변환 작업은 활성화하지 않는다. 운영에 이미 반영한 마이그레이션과 회계 Edge 소스는 이력 보존을 위해 포함하지만, 미적용 AI/회의 서버 마이그레이션과 로컬 비밀 설정은 제외한다.
