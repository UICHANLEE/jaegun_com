# 공동체 AI 연동 설계 메모

## 현재 화면

`apps/web/src/pages/AIAssistantPage.tsx`는 연결 전 프롬프트 작성 화면이다. 예시 선택, 수정, 지우기, 복사는 브라우저 메모리 안에서만 동작한다. 답변 생성 요청, 외부 네트워크 호출, API 키 입력·저장, 공동체 데이터 자동 불러오기는 없다. 프롬프트는 최대 6,000자이며, `AI_ASSISTANT_PROMPT_MAX_LENGTH` 값은 향후 서버에서도 반드시 검증해야 한다. `apps/web/src/data/aiAssistant.ts`의 `AIAssistantRequest`와 `AIAssistantResult`는 향후 서버 경계의 공급자 중립 계약 초안이다.

## 향후 요청 흐름

1. 인증된 앱 클라이언트가 명시적으로 작성한 프롬프트와 선택적 조직 범위만 자체 서버 API로 보낸다.
2. 서버는 세션과 세션 세대, 현재 필수 동의 상태, 요청 크기·빈도 한도를 확인한다. 인증 주체는 클라이언트 payload의 사용자 ID로 결정하지 않는다.
3. 조직 범위가 요청되면 서버가 해당 주체의 현재 조직 접근을 RLS/RPC 등 기존 백엔드 정책으로 다시 검증한다. 범위 이름이나 클라이언트의 UI 역할 표시는 권한이 아니다.
4. 서버는 필요한 최소 문맥만 허용된 범위에서 조회하고 외부 모델 제공자에 전달한다. 제공자 자격 증명은 서버 비밀 저장소에만 둔다. 브라우저 번들·응답·로그에 포함하지 않는다.
5. 서버는 공급자 응답을 `AIAssistantResult`로 정규화하고, 민감정보가 포함될 수 있는 요청·응답의 보존과 로그 정책을 명시적으로 제한한다.

## 권한과 안전 경계

- AI 응답은 초안/제안이며 공동체 사실, 교리적 해석, 승인 또는 공식 공지를 확정하지 않는다. 사실과 인용은 검증 가능한 근거가 있을 때만 표시한다.
- 모델이 멤버십·직분·조직 권한을 추론하거나 부여하지 않는다. 승인, 임원 배정, 게시, 회의록 확정, 회계 입력 같은 자율 쓰기는 허용하지 않는다.
- 동의가 유효하지 않거나 현재 주체가 범위에 접근할 수 없으면 보호된 문맥을 제공하지 않고 요청을 거부한다. 프롬프트 텍스트를 권한 증명이나 동의로 간주하지 않는다.
- 사용자에게 명확한 전송 고지와 실행 동의를 받은 뒤에만 프롬프트를 서버로 전송한다. 민감·개인 정보의 입력을 최소화하며, 학습 사용·보존 여부를 제공자 계약과 제품 고지에 일치시킨다.
- 서버 측 사용자/조직별 rate limit, 입력·출력 토큰 한도, 타임아웃, 재시도 상한, 비용 경보, 남용 감사를 마련한다. 서버에는 비밀이 아닌 요청 식별자와 최소 운영 메타데이터만 기록한다.
- 서비스 지역과 외부 제공자 데이터 처리 지역은 현행 동의의 해외 이전 고지와 일치하는지 출시 전에 검토한다. 처리 지역 변경은 별도의 개인정보·동의 검토 대상이다.

## 출시 전 확인

동의 및 개인정보 검토, 서버 인증·RLS 경계 테스트, 범위별 접근 테스트, rate limit·비용 한도, 응답 실패 처리, 데이터 보존·삭제 정책, 실제 배포 지역 확인을 마친 뒤 기능 플래그로 점진 출시한다. 이 설계 메모와 타입 선언은 구현이나 보안 승인으로 간주하지 않는다.
