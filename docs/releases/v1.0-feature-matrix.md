## v1.0 조건부 포함

- 기존 사진·영상 열람과 신고는 포함한다.
- iOS 1.0의 새 사진·영상 업로드 UI는 제공하지 않으며 카메라·사진·마이크 권한을 요청하지 않는다.
- 알림 화면은 앱 내 활동 함이다. APNs 푸시는 이번 버전에 포함하지 않는다.
- 계정 삭제는 14일 유예·취소 UI와 서버 처리 계약을 포함한다. 실제 출시는 worker·scheduler·알림 근거가 있을 때만 허용한다.

- iOS: iOS 16.0+, iPhone 세로 전용 Release 기기 빌드 통과; 푸시·미디어 권한 미포함; 데모 데이터 미포함

## App Review 제출 전 남은 수동 게이트

1. Apple 조직 Team ID·최종 Bundle ID를 확정하고 AASA를 JSON으로 배포한다.
2. 서명 Archive를 Validate/Upload하고 실제 iPhone과 TestFlight에서 인증·재설치·오프라인·접근성을 재현한다.
3. 합성 심사 계정 4종(회원·사역자·임원·담임목사)과 삭제 전용 계정을 준비한다.
4. 계정 삭제 worker 스테이징 근거, 15분 heartbeat, 실패 알림을 확인한다.
5. UGC 신고 처리 담당자·SLA·이의제기 근무 계획을 확정한다.
