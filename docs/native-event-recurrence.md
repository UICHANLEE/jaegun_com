# 순수 SwiftUI 반복 일정

2026-10-15 확인 기준. 웹의 신규 주차 선택 UI와 App Store 제출 완료를 뜻하지 않는다.

- 매주: 월~일 다중 선택, 1~4주 간격. 첫 시작일은 선택한 다음 요일에 맞추고 기존 일정 길이를 유지한다.
- 매월: 기존 날짜 기준 또는 첫째/둘째/셋째/넷째/마지막 + 요일 기준. 마지막은 해당 월의 그 요일 마지막 발생일이다. 1~12개월 간격, 서버의 2년 생성 범위·횟수 제한을 유지한다.
- 기준을 바꾸면 시작·종료 일시가 변경되므로 등록 전에 표시된 첫 일시를 직접 확인한다. 관리 범위와 현재 동의, 5분 이내 Google 인증, 감사, revision 충돌·중복 생성 보호는 서버에서 유지한다.
- 운영 마이그레이션 `20261014225058_event_monthly_weekday_recurrence` 적용 및 익명 RPC 실행 차단을 확인했다. 기존 반복 일정과 실제 회원/참석 응답을 재작성하지 않았다.
- 로컬 DB 테스트 39개와 iOS 테스트 50개 통과. 윤년 2월 마지막 목요일, 5회 금요일이 있는 달의 마지막 금요일, 실제 6개월 둘째 금요일 생성, 중복 요청과 다른 payload/권한 없는 요청을 검사했다.
- 웹은 기존 주간·월간 날짜 선택 UI를 유지한다. 새 월간 주차 규칙은 현재 iPhone에서 작성·수정한다. 웹이 새 규칙을 날짜 기준으로 덮어쓰는 변경은 DB의 shape/matching 제약으로 거부한다. 웹 동등 UI 확장은 남아 있다.
- 개발용 서명 빌드이며 TestFlight/App Store 제출·실사용자의 실제 일정 등록 성공은 별도 검증 항목이다.
