# 재건 공동체 — 순수 SwiftUI 전환

이 프로젝트는 Capacitor/WebView와 독립적인 iPhone 앱입니다. 화면은 SwiftUI, 데이터 통신은 URLSession, 로그인 저장은 Keychain, Google 인증은 ASWebAuthenticationSession을 사용합니다. 앱 화면이나 법적 본문을 Vercel에서 실행하지 않습니다. 기존 웹 서비스와 운영 Supabase는 보존합니다.

현재 단계: 구현 및 실제 기기 검증 진행 중. App Store 제출 완료 또는 기존 웹 전체 기능과 동등한 릴리스라는 의미가 아닙니다.

2026-10-16 출시 정리: 기본 모바일 메뉴는 홈·모임·게시판·채팅·더보기다. AI·교회·임원실·내 정보는 더보기에서 기존 네이티브 화면으로 이동한다. 운영 DB와 앱의 RPC 존재 여부가 일치하지 않으면 출시 preflight를 차단한다. `npm run check:release-rpcs -- --sql`로 현재 호출에 맞는 읽기 전용 메타데이터 SQL을 만들고, 승인된 운영 프로젝트에서 조회한 snapshot 객체를 JSON 파일로 저장한다. `npm run preflight:ios -- --rpc-snapshot=/absolute/path.json`은 15분 이내 서버 timestamp·동일 프로젝트·현재 호출 목록을 검증한다. 이 검사는 함수 존재만 확인하며 권한·시그니처·동적 호출·Edge Functions·실기기 검증을 대신하지 않는다. 과거 snapshot으로 출시를 승인하지 않는다.

2026-10-14 검증: 순수 SwiftUI 실기기 서명 빌드와 설치 성공, 동의 계약·OAuth 반환 경계 XCTest 27개 통과. 앱 번들에 Capacitor 구성이나 HTML 웹 셸이 없음. 운영 AASA JSON 응답은 서명된 앱 ID와 소셜 인증 경로 한 개만 허용합니다.

구현: 이메일 로그인·별도 회원가입, Google PKCE 시스템 인증, 명시적 14+·필수 동의, 노회→교회 가입, 사역자·연도/범위별 직책 신청·가입/직책 심사, 역할별 관리 진입, 선택 동의 기반 개인 통독·QT, 게시판 필터·검색·텍스트 게시·댓글, 채널 생성·참여·텍스트 대화, 회원 페이지 기반 DM 시작·텍스트 송수신, 한국 날짜 월간 달력·일정 생성/수정/취소·참석 응답, 로그아웃.

2026-10-15 응답성 보완: 채널·DM 요약과 최소 자기 동의 상태의 독립 조회 병렬화, 대화 상대 50행 단위 명시적 추가 조회, 중복 read 병합, 동일 세션 refresh 중 기존 화면 유지, 계정·동의·범위 변경 시 오래된 응답 폐기, 유효 토큰의 불필요한 회전 제거, 동시 갱신 이후 로그아웃/계정 변경 보호. 생성 후 실제 대화 화면으로 이동하고 메시지 맨 아래 이동을 제공한다. 서버 권한과 최신 동의 검증을 생략하거나 보호 데이터 디스크 캐시를 추가하지 않았다.

남은 출시 작업: 실제 Google 인증 복귀·본인 계정 게시/채팅/일정 end-to-end 확인, 게시글 첨부·수정/삭제·신고·차단, 리치메시지·스레드·실시간 수신·비공개 초대 관리, 조직·부서 임원 관리 전체 화면, 회의록·회계 쓰기, 계정 삭제 UI 및 운영 검증, 메일 복구 발송, 사진·영상 정책, Apple 로그인 심사 요구사항, App Store Connect 정보·프라이버시·심사 계정·TestFlight. 현재 빌드는 전환 중인 개발 앱이며 v1.0 출시 후보로 제출하지 않는다. Master v3 잔여 기능과 외부 전제조건은 `docs/master-v3-reconciliation.md`에서 별도로 관리한다.

공개 Supabase 키는 로컬 NativePublicConfig.xcconfig에만 설정합니다. 관리자 비밀 키를 넣지 않습니다. xcodegen으로 project.yml에서 프로젝트를 생성하고 JaegunNative 스킴을 빌드합니다. 실제 배포 계정·서명·TestFlight·심사 계정·개인정보 공개·UGC 운영·계정 삭제 운영·소셜 로그인 심사 요구사항은 별도 검증이 필요합니다.

동의 이전에는 개인정보 동의 RPC와 공개 문서만 조회합니다. 관리 역할은 get_my_context의 서버 결과로만 결정하며 가입 메타데이터나 UI를 권한 근거로 사용하지 않습니다.
